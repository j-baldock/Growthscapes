13  Warm-patch temperature cap test

  • Show All Code
  • Hide All Code
  • View Source

Purpose: Test whether the cold-habitat bottleneck on recruitment and abundance is partly an artifact of very high mid-summer warm-patch temperatures (~25 °C, where growth is negative at any p). We cap warm-patch temperature at 19, 21 and 23 °C in the cold+warm scenario and compare against the existing baseline cold-only and cold+warm (uncapped) runs.

13.1 Design

All runs use 25% cold habitat and the seed and parameters of Baseline_ColdWarm_025percold_rep01. The capped runs differ only in the warm-patch temperature ceiling and are shorter (20-yr burn-in + 20-yr experiment) than the baselines.

Code 
cold_prop_key <- "025"   # change to e.g. "050" to test another cold proportion
warm_caps_C   <- c(19, 21, 23)

short_len <- list(nyears_burnin = 20, nyears_experiment = 20)

base_coldwarm <- paste0("Baseline_ColdWarm_", cold_prop_key, "percold_rep01")
base_coldonly <- paste0("Baseline_ColdOnly_", cold_prop_key, "percold_rep01")
stopifnot(all(c(base_coldwarm, base_coldonly) %in% names(scenarios)))

run_defs <- tibble(
  cap           = warm_caps_C,
  run           = paste0("short_coldwarm_", cap, "C"),
  base_scenario = base_coldwarm
)

13.3 Run simulations

Results are cached to results/ and skipped if the file exists. Delete the file or set overwrite <- TRUE to rerun. Burn-in rows are dropped from ibm_long.

Code 
overwrite <- FALSE

run_capped <- function(run, base_scenario, cap) {
  out_path <- file.path("results", paste0("WarmCap_", run, ".rds"))
  if (file.exists(out_path) && !overwrite) {
    message("Skipping '", run, "' (results exist).")
    return(invisible(NULL))
  }

  params <- modifyList(scenarios[[base_scenario]], short_len)
  params$save_burnin <- FALSE

  # Cap warm-patch temperature; the cold patch is untouched
  habitat_df <- build_habitat(params) |>
    mutate(temp_warm = pmin(temp_warm, cap))

  message("Running '", run, "' ...")
  t0  <- Sys.time()
  res <- run_simulation(habitat_df = habitat_df, params = params, wt_growth = wt.growth)
  attr(res, "run_time_secs") <- as.numeric(difftime(Sys.time(), t0, units = "secs"))
  saveRDS(res, out_path)
  invisible(NULL)
}

pwalk(run_defs, \(cap, run, base_scenario) run_capped(run, base_scenario, cap))

13.4 Load results

Each file is reduced to what we need before binding, so the full ibm_long objects aren’t held in memory together. Oct 1 census rows give abundance, biomass, recruitment and weight-at-age. Summer age-0 rows (Jun-Aug) give patch use.

Code 
baseline_files <- tibble(
  run  = c("baseline_coldonly", "baseline_coldwarm"),
  path = file.path("results", paste0(c(base_coldonly, base_coldwarm), ".rds"))
)
capped_files <- run_defs |>
  transmute(run, path = file.path("results", paste0("WarmCap_", run, ".rds")))

all_files <- bind_rows(baseline_files, capped_files)

reduce_run <- function(run, path) {
  res <- readRDS(path)
  ibm <- res$ibm_long

  # Experiment start: 20 yr for capped runs, baseline burn-in length otherwise
  nburn <- if (startsWith(run, "short")) short_len$nyears_burnin else base_params$nyears_burnin
  exp_start <- base_params$mindate + years(nburn)

  oct1 <- ibm |>
    filter(date >= exp_start, month(date) == 10, day(date) == 1, survived == 1) |>
    mutate(run = run, year = year(date), age_class = floor(age))

  summer_age0 <- ibm |>
    filter(date >= exp_start, month(date) %in% 6:8, survived == 1, floor(age) == 0) |>
    count(year = year(date), patch) |>
    mutate(run = run)

  list(oct1 = oct1, summer_age0 = summer_age0)
}

reduced <- pmap(all_files, reduce_run)

oct1        <- map_dfr(reduced, "oct1")
summer_age0 <- map_dfr(reduced, "summer_age0")
rm(reduced)

run_levels <- c("baseline_coldonly", "baseline_coldwarm", run_defs$run)
oct1        <- oct1        |> mutate(run = factor(run, levels = run_levels))
summer_age0 <- summer_age0 |> mutate(run = factor(run, levels = run_levels))

13.8 Mechanism check: do age-0 fish use the warm patch in summer?

If the hypothesis is right, capped runs (especially the lower caps) should show a nontrivial share of age-0 fish in the warm patch in Jun-Aug, and the uncapped baseline should show about none. Shares are fish-days summed over Jun-Aug of each year.

13.9 Interpretation notes

  • Compare each capped run to baseline_coldwarm for the effect of the cap, and to baseline_coldonly for whether warm habitat now helps relative to cold-only.
  • Capped runs have a 20-yr burn-in versus 50 yr for the baselines. Check the time series for trends, which would indicate the capped runs have not equilibrated.
  • With one seed per run, differences smaller than the interannual SD should not be over-interpreted. If a result is borderline, add replicates using the sim_seed values already in ScenarioDefs.R.
